# FAQ-бот репетиции


Консольный FAQ-бот для репетиции. Он отвечает на пять заранее известных вопросов: о времени, размере команды, выборе трека, сдаче работы и призах. Если бот не находит подходящего вопроса, он честно отвечает: Не знаю.

## Возможности


- Чат в терминале: бот принимает вопросы до команды выхода.
- Пять пар «вопрос — ответ» хранятся отдельно в faq.txt.
- Поиск не требует RAG, нейросетей или внешних библиотек: он сравнивает ключевые слова.
- Учтены простые формы слов. Например, запросы «размер команды» и «как сдать работу» корректно сопоставляются с вопросами из FAQ.
- Неизвестная тема не приводит к случайному ответу: выводится Не знаю.

## Запуск


1. Установите Go версии 1.22 или новее.
2. Откройте терминал в корне репозитория.
3. Запустите программу:


```bash
go run .
```


Для сборки исполняемого файла можно выполнить:


```bash
go build -o faq-bot .
./faq-bot
```


## Как пользоваться


После запуска напишите вопрос обычным текстом. Например:


```text
FAQ-бот репетиции. Задайте вопрос или напишите «выход».
> Когда будет репетиция?
Репетиция проходит в пятницу, 27 сентября, с 18:00 до 20:00.
> Какой размер команды?
В команде должно быть от 2 до 5 участников.
> Как сдать работу?
Сдайте ссылку на репозиторий команды до 20:00 в день репетиции.
> Что по питанию?
Не знаю.
> выход
До встречи!
```


Чтобы завершить работу бота, введите выход. Также поддерживаются команды exit и quit.


## Как работает поиск ответа


1. При запуске бот читает faq.txt. Каждая непустая строка в нём имеет формат вопрос|ответ.
2. В вопросах пользователя и FAQ бот выделяет слова, приводит их к нижнему регистру и убирает распространённые служебные слова: «как», «когда», «и» и другие.
3. Для каждой FAQ-записи подсчитывается количество совпавших ключевых слов. Совпадением также считается одинаковое начало из трёх букв у слов длиной от четырёх букв — это помогает сопоставить «команды» и «команда».
4. Бот печатает ответ с наибольшим числом совпадений. Если совпадений нет, выводится Не знаю.


## Изменение FAQ


Чтобы заменить вопросы или ответы, отредактируйте faq.txt, не меняя формат строки:


```text
Вопрос?|Ответ.
```


После сохранения изменений перезапустите программу. Новые зависимости или изменения кода для этого не нужны.
